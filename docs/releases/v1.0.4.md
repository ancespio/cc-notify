# Agents-Notify v1.0.4

## 主要变化

- 飞书通知统一使用 HTTP OpenAPI，不再依赖本机 `lark-cli` 登录态或命令行进程。
- 飞书 WebSocket 仍用于接收机器人消息，并与 HTTP OpenAPI 共用 App ID、App Secret 和 `open_id` 配置。
- 设置界面和首次配置向导改为直接配置飞书 App ID、App Secret 与接收人 `open_id`。
- 旧配置中的 `lark_cli` 字段会在迁移时移除，并先按既有规则备份。

## 验证

- `python -m unittest discover -s tests -q`
- `python -m compileall -q agents_notify desktop_app.py desktop_hook.py notify_hook.py setup_guide.py tray.py`
- 冻结 EXE 运行时、设置页和首次配置向导烟雾测试通过。
- 安装后版本、注册表信息和安装目录 EXE 已核对。

## 安装包

下载并运行 `Agents-Notify-Setup-v1.0.4.exe`。安装器沿用既有 AppId，可覆盖升级旧版本；
已有配置会保留并按配置迁移规则处理。
