# Agent-Notify v1.0.0

Agent-Notify 的首个正式版本，面向 Codex 与 Claude Code 提供 Bark、飞书通知及飞书远程控制。

## 主要功能

- 支持 Codex 与 Claude Code 的权限申请、结构化提问和任务完成 Hook。
- Bark 与飞书通知可独立启用，并分别选择全部通知、仅 SSH 或关闭。
- 飞书远程控制与飞书通知独立，可通过 `/notify` 命令切换两个渠道。
- 提供统一中文设置窗口、Windows 托盘和登录自启动。
- 使用 Agent-Notify 自有图标，不再使用 Bark 默认图标。
- 配置采用跨进程锁与原子替换，网络或 Provider 失败不会阻塞 Agent。
- 安全合并 Codex、Claude Code Hook，不写入 `AGENTS.md`。

## 安装

下载并运行 `Agent-Notify-Setup-v1.0.0.exe`。安装完成后会打开设置窗口，可配置 Bark、飞书、Agent Hook 与登录自启动。

## 已知限制

- Bark 和 Apple Watch 通知不支持直接批准或拒绝 Agent 权限请求。
- Bark 通知默认通过 `chatgpt://` 打开 ChatGPT App，不保证跳转到具体 Codex 线程。
