# Agent-Notify v1.0.1

## 配置体验修复

- 修复 Windows 下 Bark Key 无法切换为明文显示的问题。
- 安装完成后启动五步首次配置向导，Bark 与飞书均可跳过。
- 增加旧版 Bark 跳转和图标提示，并提供“恢复新版默认”按钮。
- 增加远程图标下载、格式、尺寸、大小和 SHA-256 校验及预览。
- Bark 测试通知必须通过图标校验，Hook 正常通知保持快速且 fail-open。
- 增加 `lark-cli` 安装、初始化、登录、状态检测和自动获取 `open_id` 的分步引导。
- 飞书连接消息自动建立并保存只读 `chat_id`。
- 普通设置页可重新运行配置向导。

## 安装

下载并运行 `Agent-Notify-Setup-v1.0.1.exe`。安装完成后会自动打开首次配置
向导；双击已安装的 `Agent-Notify.exe` 仍打开普通设置页。
