# Agent-Notify v1.0.2

## 热修内容

- Bark 与飞书统一使用全部通知、仅 SSH、关闭三种模式，不再保留单独的通知开关。
- 默认 Bark 跳转调整为 `chatgpt://codex`，图标 URL 固定到 `master` 分支。
- 旧配置加载时自动备份并幂等迁移，自定义值和凭据保持不变。
- 修复 PyInstaller onefile 托盘无法打开设置或重启自身的问题。
- Bark 测试按配置、图标和推送阶段返回明确错误，并写入脱敏日志。
- 托盘提示直接显示 Bark、飞书模式与遥控状态，并在远程命令后立即刷新。
- 托盘新增飞书遥控开关和飞书测试通知，配置不完整时自动打开飞书设置页。
- 设置页改用横向三态选择器和可滚动标签页，修复 Bark 测试按钮被遮挡的问题。
- 飞书 `on`、`ssh`、`off` 直接切换通知模式，多行状态使用 JSON 内容回复。
- 飞书远程控制开关继续保持独立。
- 增加 `lark-cli` 版本检测和可见 PowerShell 更新入口。

## 安装

下载并运行 `Agent-Notify-Setup-v1.0.2.exe`。可直接覆盖升级 v1.0.1，现有
Bark Key、飞书身份、Hook 选择及自定义通知地址会保留。
