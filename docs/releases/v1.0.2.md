# Agent-Notify v1.0.2

## 热修内容

- 默认 Bark 跳转调整为 `chatgpt://codex`，图标 URL 同步到 v1.0.2 tag。
- 旧默认配置首次加载时自动备份和迁移，自定义值保持不变。
- 修复 PyInstaller onefile 托盘无法打开设置或重启自身的问题。
- Bark 测试按配置、图标和推送阶段返回明确错误，并写入脱敏日志。
- 飞书 `on`、`ssh`、`off` 同时控制通知渠道开关和模式。
- 飞书多行状态使用 JSON 内容回复，远程控制开关继续保持独立。
- 增加 `lark-cli` 版本检测和可见 PowerShell 更新入口。

## 安装

下载并运行 `Agent-Notify-Setup-v1.0.2.exe`。可直接覆盖升级 v1.0.1，现有
Bark Key、飞书身份、Hook 选择及自定义通知地址会保留。
