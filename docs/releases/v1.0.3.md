# Agents-Notify v1.0.3

## 主要变化

- 飞书遥控改用官方 `lark-oapi` WebSocket 长连接接收
  `im.message.receive_v1`，不再轮询消息历史。
- 设置页、首次向导和配置文件新增飞书 App ID/App Secret；长连接仅接受已配置
  用户与私聊会话的新消息，并按消息 ID 去重。
- README 增加企业自建应用、机器人权限、App ID/App Secret、长连接事件和发布
  流程的完整配置说明。
- 飞书主动通知和连接测试暂时继续使用 `lark-cli`；通知模式与远程控制开关保持
  相互独立。
- 补充 WebSocket 服务单元测试和冻结打包依赖。

## 升级

下载并运行 `Agents-Notify-Setup-v1.0.3.exe`。安装器沿用既有 AppId，可覆盖升级
v1.0.2；旧配置会先备份再迁移，原有 Bark Key、飞书 open_id/chat_id、通知模式、
Hook 和自启动选择保持不变。

升级后如需启用飞书遥控，请按 README 填写 App ID/App Secret，并在飞书开发者
后台启用长连接、订阅 `im.message.receive_v1`、发布应用版本。
